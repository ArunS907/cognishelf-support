# CogniShelf Support

This repository is for support, bug reports, feedback, and feature requests for CogniShelf.

## Report a problem

If you encounter a problem while using CogniShelf, please open an Issue.

When reporting a bug, include:
- What you were trying to do
- What happened
- What you expected to happen
- Browser/device
- Screenshot if useful

Please do not include passwords, API keys, authentication tokens, private research notes, or other sensitive information.

## Feature requests

Feature suggestions are also welcome through GitHub Issues.
